# Drawn - Frontend

The frontend for Drawn, a multiplayer drawing and NFT sticker game built on Linera blockchain.

## Tech Stack

- **Vite** - Fast build tool and dev server
- **React 18** - UI framework with TypeScript
- **shadcn/ui** - Component library built on Radix UI
- **Tailwind CSS** - Utility-first styling
- **React Router** - Client-side routing
- **TanStack Query** - Data fetching and state management

## Getting Started

### Prerequisites

- Node.js 18+ and npm (or bun)
- Linera GraphQL service running on port 8081
- Linera faucet on port 8080

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The frontend will be available at **http://localhost:5173**

### Build

```bash
# Production build
npm run build

# Preview production build
npm run preview
```

## Integration with Linera Blockchain

The frontend communicates directly with the Linera blockchain via GraphQL:

**Linera GraphQL Service** (port 8081)

- GraphQL API for smart contract interactions
- Mutations: `start`, `makeMove`
- Queries: `board`, `players`

## Environment Variables

Create a `.env.local` file in the frontend directory (auto-generated by run.bash):

```env
VITE_APP_ID=<application_id>
VITE_CHAIN_ID=<chain_id>
VITE_OWNER_ADDRESS=<owner_address>
VITE_GRAPHQL_ENDPOINT=http://localhost:8081
```
